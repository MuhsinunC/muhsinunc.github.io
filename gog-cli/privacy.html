Privacy policy: gog CLI (personal)

Last updated: 18 October 2026

gog CLI (personal) is a private command-line tool used only by its owner, on his own computer, with his own Google account. See the home page.

What data it accesses

When the owner runs a command, the tool calls Google APIs for the Google services he grants: Google Drive, Docs and Sheets (his own files), Google Calendar (his own events) and Google Contacts (read-only). It accesses only the data a given command needs.

Where data is stored

Data is processed only on the owner's own computer. The sign-in tokens are stored encrypted on that computer. The tool has no server, and nothing is sent to anyone other than Google's own APIs.

Sharing

No data is sold, shared with or transferred to any third party, or used for advertising. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the tool's local token file removes the stored sign-in.
